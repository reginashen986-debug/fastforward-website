## creative.html 修复：视频无法点击播放的问题

**问题**：移除 video 的 `controls` 属性后，视频变成了静态图片，无法点击播放。

**原因**：没有 controls 属性后，video 本身没有内置播放入口，页面也没有任何播放按钮。

**解决方案**：
1. 每个 `.vs-ctrl` 叠加层新增播放按钮（`vs-btn-play`）
2. 视频暂停时，卡片中央通过 `::after` 伪元素显示大播放三角图标（`.video-paused::after`）
3. 播放按钮图标在播放中自动变为暂停图标（`rect` 竖条），暂停时变为播放三角（`polygon`）
4. 移动端（`@media (hover: none)`）：叠加层始终可见，不依赖 hover 事件
5. 点击播放按钮 → `video.play()` / `video.pause()`
6. 点击卡片其他区域 → 保持原有逻辑（切换声音开/关）

**提交**：`0b54eea fix(creative): 添加播放按钮，解决无controls后视频无法点击播放的问题`

## 第二次修复：克隆卡片播放按钮不工作（事件委托）

**问题**：`initMarquee` 用 `cloneNode()` 克隆卡片，但 JS 事件监听器不会跟着克隆，导致克隆卡片的播放按钮失效。

**根因**：原代码用 `document.querySelectorAll('.vs-card').forEach()` + `addEventListener` 绑定，只对原始 DOM 有效。

**修复方案**：
- 改用 `document.addEventListener('click', ...)` 事件委托 + `e.target.closest('.vs-card')` 获取卡片
- 新增 `bindVideoStateListeners()` 函数监听视频 play/pause 事件
- `initMarquee` 调用后执行一次 `setTimeout(bindVideoStateListeners, 0)` 给克隆卡片绑定状态
- 播放/暂停/全屏/静音/卡片点击统一走事件委托

**提交**：`143c0b0 fix(creative): 改用事件委托，修复克隆卡片播放按钮无法点击的问题`

## 方案C：解决安卓微信X5无法识别视频问题

**问题**：移除 `controls` 后安卓微信（X5 内核）不识别视频为可播放元素，视频显示为黑块/图片，无法播放。

**根因**：X5 内核要求 `<video>` 必须有 `controls` 属性才会渲染为可播放状态。

**方案C 解法**：
- 所有 `<video>` 加回 `controls` 属性（保留 controlsList="nodownload noremoteplayback"）
- CSS 让 video `height: calc(100% + 44px)` + `margin-bottom: -44px`，把原生控件栏（44px）推出 `.vs-card` 的 `overflow: hidden` 裁剪范围外
- 原生控件栏在视觉上彻底消失，下载按钮也随之消失
- 自定义 `.vs-ctrl` 叠加层（播放/全屏/静音）仍正常工作

**提交**：`dbcd9dc fix(creative): 方案C — 加回controls+CSS裁剪控件栏，解决安卓微信X5无法播放问题`
