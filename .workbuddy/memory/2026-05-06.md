## index.html 首页「我们的创作实力」视频黑屏修复
- 根本原因：`scrollWidth` 在父容器 `overflow:hidden` 下等于父容器可见宽度，不是内容真实宽度。之前所有基于 scrollWidth 的方案都只拿到了可见宽的一半，offset 瞬间就 >= halfWidth 触发重置，看起来视频固定不动
- 终版方案：完全放弃 scrollWidth，改用 `allCards[0].offsetWidth × origCount + gap × (origCount-1)` 精确计算半段宽度
  - 竖屏：7卡 × 330px + 6 × 21px = 2436px
  - 横屏：3卡 × 570px + 2 × 21px = 1752px
- 已推送 commit: 552e419

## index.html 首页「我们的创作实力」视频黑屏修复
- 根本原因：CSS 里 `.vsb-video-stack video` 的 `}` 提前关闭，`transition: opacity 0.8s` 变成游离代码，导致 CSS 解析错误，video.active 的 `opacity:1` 无法生效，所有视频永远 opacity:0（黑屏）
- 修复：将 transition 属性移入正确的 `.vsb-video-stack video {}` 块内
- 已推送 commit: 89bf52b


## creative.html 走马灯滚动修复（第二次）
- 根本原因：`.video-scroll-track` 设置了 `overflow-x: auto`，`.auto-scroll` 尝试用 `overflow-x: visible` 覆盖，但父容器 `.vs-marquee-wrap` 是 `overflow: hidden`，子元素 overflow:visible 无效，导致 track 宽度被限制在容器内，`scrollWidth` 和 `offsetWidth` 读到的是压缩后的值，走马灯无法移动
- 修复：`.auto-scroll` 加 `!important` 强制覆盖 `overflow: visible`、取消 `scroll-snap-type`，同时 `getHalfWidth()` 改为优先读 `scrollWidth`，启动延迟改为 200ms
- 已推送 commit: 6493e51
